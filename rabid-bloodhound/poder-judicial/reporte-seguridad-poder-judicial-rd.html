📊 Resumen Ejecutivo

137|

Se identificó una fuga crítica de datos personales en la API pública del sistema de gestión de casos del Poder Judicial. 138|

Adicionalmente, se descubrieron múltiples vectores secundarios que exponen información de infraestructura interna, esquemas de base de datos, errores SQL detallados, y catálogos institucionales completos.
